# Financial Web Interface 💳

A web-based platform designed to showcase modern user interface patterns for financial services. This project was developed to master the integration between **Flask** backends and dynamic **HTML/CSS** frontends, with a strong emphasis on user experience and modularity.

## ✨ Key Highlights

* **Multi-language Support (i18n)**: Built-in internationalization system with JSON-based translation files for English and Spanish.
* **Responsive Design**: Clean and professional CSS styling focused on a minimalist aesthetic.
* **Flask Integration**: Demonstrates how to bridge web templates with Python-based business logic.
* **Clean Architecture**: Organized folder structure separating data handling, business rules, and presentation templates.

## 🛠️ Tech Stack

* **Backend**: Python / Flask
* **Frontend**: HTML5, CSS3
* **Data Format**: JSON (for both persistence and localization)
* **Architecture**: Layered Pattern

## 🏗️ Project Structure

* `/presentation`: Contains the HTML templates and the minimalist CSS stylesheet.
* `/business`: Handles the logic for processing user sessions and data flow.
* `/data`: Manages persistent information using JSON structures and helper scripts.

## 🚀 How to Run

1. **Clone the repository**:
   ```bash
   git clone [https://github.com/your-username/wallet-page-project.git](https://github.com/your-username/wallet-page-project.git)
   cd wallet-page-project
   ```

2. **Install Flask**:
  ```bash
  pip install Flask python-dotenv
  ```

3. **Launch the server**:
  ```bash
  python main.py
  ```
